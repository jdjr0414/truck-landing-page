What Is CDL Class B?

CDL Class B is a Commercial Driver's License that allows operation of single vehicles with a Gross Vehicle Weight Rating (GVWR) of 26,001+ lbs. Class B covers dump trucks, bucket trucks, vac trucks, garbage trucks, cement trucks, and other single heavy vehicles. Class B holders cannot operate tractor-trailer combinations (Class A vehicles).

Key Takeaways

  • Class B covers single vehicles over 26,000 lbs GVWR
  • Required for dump trucks, bucket trucks, vac trucks, garbage trucks
  • Class B does not allow operation of tractor-trailer combinations
  • Common for construction, utilities, and environmental services

Quick Answer

CDL Class B is required for single vehicles (no trailer, or trailer under 10,000 lbs GVWR) with a Gross Vehicle Weight Rating of 26,001+ lbs. It covers dump trucks, bucket trucks, vac trucks, garbage trucks, cement trucks, street sweepers, and other vocational trucks. Class B holders cannot operate Class A vehicles (tractor-trailer combinations).

Vehicles Requiring Class B CDL

  • Dump trucks
  • Bucket trucks (aerial work)
  • Vac trucks (vacuum excavation, septic)
  • Garbage trucks
  • Cement trucks (ready-mix)
  • Street sweepers
  • Tow trucks (over 26,000 lbs GVWR)
  • Flatbed straight trucks
  • Box trucks (over 26,000 lbs GVWR)

Class B vs Class A

Class B covers single vehicles. Class A covers combination vehicles (tractor + trailer). If you pull a trailer over 10,000 lbs GVWR with a tractor over 26,000 lbs, you typically need Class A. Class A holders can operate Class B vehicles; Class B holders cannot operate Class A vehicles.

Common Questions

What trucks can I drive with a Class B CDL?

Single vehicles over 26,000 lbs GVWR — dump trucks, box trucks, bucket trucks, garbage trucks, and buses — but not tractor-trailers over the combination threshold.

Is a Class B CDL enough to start a vocational truck business?

For most single-unit vocational trucks (dump, bucket, vac), yes. Towing a trailer over 10,000 lbs pushes you into Class A territory.

Can I upgrade from Class B to Class A later?

Yes. You take the Class A knowledge and skills tests; your existing experience and endorsements carry over.
